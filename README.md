# News Project

A simple PHP news website with a home page, single news page, and category pages.

## Structure

- `index.php` — home page listing all news items
- `content.php` — single news content page
- `category.php` — category listing page
- `data/news.php` — sample data source
- `includes/header.php` — header layout
- `includes/footer.php` — footer layout
- `includes/functions.php` — helper functions
- `assets/css/style.css` — basic styles
- `assets/images/` — image folder

## Setup

1. Place the folder under your web server root.
2. Open `index.php` in a browser.
